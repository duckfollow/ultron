## Ultron v0.1.0-alpha.11

- Rich Output opens automatically in new local zsh sessions. For SSH, source the shell integration script in the remote zsh session.
- Browse Docker containers, images, and Compose services in searchable tables. Read one-shot Docker logs with search, timestamps, and severity highlights.
- View disk space and usage bars with `df` or `df -h`.
- Review staged, unstaged, untracked, and conflicted paths with `git status`. View commit history with `git --no-pager log -n 20`.
- Switch to Raw to inspect or copy command output. Use the Info button to reopen the latest result.
- Find **Export folder** in the connection folder's **⋯** menu.

### Install

For Apple Silicon Macs running macOS 13.5 or later. Quit Ultron before replacing the app. This build is ad-hoc signed and is not notarized by Apple.
